# Getting Help

Squire is files. There is no server to be down, no account to be locked out of, and no
support queue. But if you are stuck, here is where to go — routed by what you need.

## Where To Go

| I want to... | Go here |
|--------------|---------|
| **Ask a question** ("how do I...", "does Squire support...") | [GitHub Discussions](https://github.com/eddiebelaval/squire/discussions) — the Q&A category |
| **Report something broken** (bad path, installer error, wrong doc) | [Open a bug report](https://github.com/eddiebelaval/squire/issues/new?template=bug-report.md) |
| **Propose a skill, command, agent, or rule** | [Open a feature request](https://github.com/eddiebelaval/squire/issues/new?template=feature-request.md) |
| **Submit a finished skill** | [Open a skill submission](https://github.com/eddiebelaval/squire/issues/new?template=skill-submission.md) |
| **Contribute code or docs** | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| **Reach the maintainer directly** | X: [@eddiebe](https://x.com/eddiebe) |

## The Community Channel

Squire's community forum is **GitHub Discussions**, not Discord or a hosted forum. This is
deliberate: Discussions is where the code, the issues, and the contributors already are;
it needs no separate account, no invite link, and no moderation infrastructure to keep
running. It is the file-based project's file-based forum. If Discussions ever proves
insufficient, a dedicated channel will be evaluated — but the default is to keep help
close to the repository.

## Before You Ask

Most answers are already in the repo:

- **[README.md](README.md)** — what Squire is, how to install it, what every component does.
- **[SPEC.md](SPEC.md)** — the precise current capabilities and boundaries.
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — how to add or change anything.
- **`install.sh --help`** — installer flags (`--dry-run`, `--commands-only`, `--uninstall`).

A good question names what you tried, what you expected, and what happened instead. That
gets you a real answer instead of a round of clarifying questions.
