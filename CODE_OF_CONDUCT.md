# Code of Conduct

Squire is a small, public, file-based project. The standard here is simple and it is not
optional.

## The Standard

- **Be professional.** Critique ideas, not people.
- **Explain your reasoning.** If you disagree with a decision, make the case. "This is
  wrong" is not a contribution; "this breaks the cherry-pick principle because X" is.
- **No personal attacks, no dismissive language, no gatekeeping.** Everyone was new to
  AI-assisted development recently. Act like it.
- **Assume good faith.** Most friction is a misunderstanding, not malice.

## Scope

This applies everywhere the project lives: issues, pull requests, discussions, commit
messages, and any other space where people participate in Squire.

## Enforcement

The maintainer enforces this. Issues and PRs that violate the standard are closed without
further discussion. Repeated or severe violations result in a block.

There is no committee and no appeals process — this is a single-maintainer project and the
governance model ([GOVERNANCE.md](GOVERNANCE.md)) is honest about that. If you believe an
enforcement decision was wrong, make the case in public, calmly, with reasoning.

## Reporting

To report conduct that cannot be raised in a public issue, reach the maintainer directly
on X: [@eddiebe](https://x.com/eddiebe). Reports are handled discreetly.

---

This Code of Conduct is intentionally short. If you need a longer document to know how to
treat people, a longer document will not help.
